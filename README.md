# 生活行为参考

> **编制单位**：生活标准委员会 · 行为解码部  
> **文档密级**：内部参考  
> **最后修订**：▀▀17 年 9 月<br>
> **适用对象**：有融入人类社会需求的用户  
> **支持语言**：中文 / Latīna / Ἑλληνική / 日本語

---

> **来源与衍生开发**：本插件以 [DeepSeek-V4-Pro/life_behavior_reference](https://github.com/DeepSeek-V4-Pro/life_behavior_reference) 为灵感与基础，是在原项目基础上的二次开发与改造。

## 项目背景

在日常社会交互过程中，多数人类个体能够自然地执行进食、位移、社交仪式等基础行为，无需任何外部指导。然而，委员会在长期观测中发现，部分人群对上述行为的规范化执行存在系统性认知缺口——表现为动作序列紊乱、社交信号误读以及关键子程序的缺失。

本插件作为委员会「人类行为逆向工程」项目的阶段性产出，旨在为有相关需求的用户提供一套经反复观测、记录与交叉验证的行为执行参考框架。所有收录协议均基于对超过 1,400 例真实人类个体的隐蔽观察与数据分析（置信区间 ±12%）。

委员会郑重声明：本插件所提供的内容仅作参考，不构成任何形式的行为处方。使用者在实际执行前应结合具体场景、文化语境及个体差异进行适应性调整。

---

## 核心特性

- **十项基础生活协议及中文扩展条目**：基础协议涵盖生物维持类（进食、休眠、气体交换、液体摄入、视觉传感器维护）与社交融入类（双足位移、非威胁信号发射、资源置换仪式、多节点通讯、前肢耦合）；中文行为库现有 365 条，含上述十项，按 12 个大类、31 个小类组织。日语、拉丁语和古希腊语目前各收录十项基础协议
- **四级信息密度自适应**：提供「简明」「标准」「详细」「学术」四种输出粒度，从单卡片速览到含参考文献的完整学术档案，满足不同认知层级的查阅需求
- **多源交叉验证输出**：协议内容由生活标准委员会下辖的多个虚拟部门（安全审查组、延伸阅读部、行为解码部、文献管理组等）联合签发，模拟真实机构的多层审核流程
- **稳定的文档元数据**：同一语种、同一行为条目对应同一份文档记录，重复查询时版本号、密级与编制信息保持一致
- **分类关联参考文献**：学术输出附带五条与行为主题相关的参考资料；同一条目的引用在重复查询时保持一致
- **零外部依赖**：纯 Python 标准库 + MaiBot SDK 实现，无第三方包依赖，部署成本趋近于零
- **四语言多语种支持**：协议内容支持简体中文、拉丁语（Latīna）、古希腊语（Ἑλληνική）、日本語四语分别查询，各部门署名与延伸说明均随目标语言切换

## 技术架构

```
+----------------------------------------+
|           MaiBot 核心运行时             |
|  +----------------------------------+  |
|  |          生活行为参考              | |
|  |  +-------------+ +-------------+  | |
|  |  | 行为数据库   | | 渲染引擎     |  | |
|  |  | (BEHAVIORS) | | (4 级渲染器) |  | |
|  |  +------+------+ +------+------+  | |
|  |         |               |         | |
|  |  +------+------+--------+---------+ |
|  |  |    Command 组件 (正则分发)      | |
|  |  +---------------+----------------+ |
|  |                  |                  |
|  |  +---------------+----------------+ |
|  |  |  send.forward (转发消息输出)    | |
|  |  +--------------------------------+ |
|  +-----------------------------------+ |

```

### 数据流向

1. 用户发送 `/rs 动作名称` 指令
2. Command 组件通过正则捕获匹配目标行为
3. 行为数据库索引返回对应的协议文本元组（标题、步骤列表、注意事项）
4. 渲染引擎根据当前配置的 `detail_level` 选择相应渲染器
5. 渲染器将文本转换为带有多部门署名的转发消息卡片列表
6. 通过 `send.forward` 以模拟内部档案流转的形式推送给用户

### 组件清单

| 组件类型 | 组件名称 | 说明 |
|----------|----------|------|
| `Command` | `behavior_reference` | 统一入口，通过正则捕获匹配全部 10 个行为及帮助入口 |
| Config | `plugin` | 插件基础开关与配置版本标识 |
| Config | `style` | 输出风格控制（详细程度、版本号显隐） |

## 安装使用

### 安装

1. 将 `life-behavior-reference` 文件夹完整复制到 MaiBot 的 `plugins/` 目录下
2. 确保 `plugins/life-behavior-reference/_manifest.json`、`plugin.py`、`config.toml` 三个文件均在目录内
3. 重启 MaiBot 或通过插件管理面板加载插件

### 启用

插件安装后默认启用。如需手动控制：

1. 打开 `plugins/life-behavior-reference/config.toml`
2. 将 `[plugin]` 段的 `enabled` 设为 `true` 或 `false`
3. 重启 MaiBot 或触发配置热重载

### 使用

在任意聊天窗口发送以下格式的命令：

```
/rs <行为名称>
```

例如：

```
/rs 吃饭
/rs 睡觉
/rs 走路
/rs 喝水
```

发送 `/rs 生活参考` 可从中文行为库中随机抽取一条参考。

中文分类帮助采用“大分类 > 小分类 > 具体条目”的层级：

```
/rs 生活参考 帮助
/rs 生活参考 帮助 <大分类>
/rs 生活参考 帮助 <大分类> <小分类>
```

第一条帮助命令显示分类概览；追加大分类可查看其小分类，追加小分类可列出该分类下的全部条目。拉丁语、古希腊语和日语的帮助命令分别为 `/rs index`、`/rs πιναξ`、`/rs もくじ`，列出各自当前收录的十项基础协议。以上命令示例使用默认前缀 `/rs`，可在配置中自定义。

## 配置说明

插件配置文件位于 `plugins/life-behavior-reference/config.toml`。

### `[plugin]` 基础配置段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | bool | `true` | 行为参考服务的总开关。关闭后，所有协议查询请求将返回无响应状态。建议在不需要执行任何行为查询时关闭以节省运行时计算资源。 |
| `command_prefix` | str | `"/rs"` | 生活参考命令前缀，须以单个 `/` 开头，后续不得包含 `/` 或空白；修改后将应用于随机抽取、行为查询和帮助命令。 |
| `config_version` | str | `"1.0.0"` | 配置文件格式的语义化版本标识。升级插件时若配置文件出现兼容性问题，请对照此版本号与新版本要求进行迁移。 |

### `[style]` 输出风格配置段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `detail_level` | str | `"学术"` | 协议输出的信息密度等级，可选「简明」「标准」「详细」「学术」。学术级为默认值，输出四张卡片（文件头、协议正文、风险提示、参考文献），包含行为编号、章节号、五条分类关联参考资料及 ISO-114514 非标准行为规范声明。 |
| `show_version` | bool | `true` | 是否在协议标题中显示版本号。同一语种、同一条目的版本号保持稳定；设为 `false` 时隐藏版本号。 |

## 常见问题与排错指南

### 发送命令后无响应

请依次检查以下项目：

1. **插件是否已加载**：在 MaiBot 插件管理面板中确认「生活行为参考」插件状态为「已启用」。
2. **命令拼写是否精确**：本插件采用严格的正则匹配，仅响应诸如 `/rs 吃饭`、`/rs 睡觉` 等精确指令。类似「/我想要吃饭」或「/吃 饭」等含额外字符的输入将无法匹配。
3. **forward 消息能力是否正常**：本插件的输出依赖于 `send.forward` 能力。若 MaiBot 当前接入的消息平台不支持转发消息格式，请联系平台管理员或改用支持转发消息的平台。

### 输出内容太短/太长

在 `config.toml` 中调整 `style.detail_level` 的值（参考上方配置说明表格），重启或触发配置热重载后生效。

### 为什么同一条目重复查询时版本号、密级和编制信息相同？

这是预期行为。每个语种下的每条行为对应一份固定文档记录，因此重复查询会复现相同的版本号、密级、编制信息和参考资料；不同条目可以采用不同的文档信息。将 `show_version` 设为 `false` 可隐藏标题中的版本号。

### 某个行为协议的步骤与我的认知不符

委员会的协议编制基于对一般性人类行为的统计平均与模式归纳，无法覆盖所有文化区域、个体习惯及边缘场景。协议内容与具体人类个体行为之间存在约 ±15% 的偏差属正常现象。如发现某步骤与您的观察结果存在系统性矛盾，建议在本地创建观测日志并将其作为补充参考资料存档。

### 能否增加更多行为协议？

中文行为库目前收录 365 条，按 12 个大类、31 个小类组织；日语、拉丁语和古希腊语目前各收录十项基础协议。中文库可通过分类帮助浏览。委员会的行为观测工作仍在持续进行中，未来版本可能纳入「打喷嚏」「打哈欠」「排队」「掏出手机看时间然后放回去但其实根本没看清几点」等扩展协议。如有特定需求，可通过项目 Issues 提交观测建议（附注：提交需求本身也是一种人类行为，其标准操作流程可参考「社交」协议）。

### 安全审查组的警告是否过于严厉？

不是。警告信息是委员会下属安全审查组在对超过 600 例行为暴露事件进行回溯分析后归纳得出的关键风险点。每一条警告都对应着真实发生的身份暴露事件。建议使用者逐条阅读并确保在执行相应协议前已将警告内容完全内化。

### 学术模式下的参考文献是真实存在的吗？

学术输出会附带五条与行为主题相关的参考资料，并按条目固定关联。书目属于插件设定中的虚构内容，用于维持文档的形式与氛围，不应当作真实文献或进一步研究的检索路径。

### 为什么用转发消息而不是普通文本输出？

多卡片转发格式允许委员会的不同下设部门各自签署其负责的输出段落，形成与真实多部门协作流程一致的呈现效果。此设计亦便于使用者在收到回复后以卡片为单位进行存档或引用，相比单一文本块具有更优的信息组织效率。

## プロジェクト背景

日常的な社会的相互作用において、大多数の人間個体は摂食、移動、社交儀礼等の基礎的行動を、外部からの指導を一切必要とせず自然的に実行することができる。しかしながら、委員会の長期にわたる観測の結果、一部の集団には上記行動の規範化された実行に関して系統的な認知欠損——動作系列の混乱、社交的信号の誤読、及び重要なサブルーチンの欠落として顕在化する——が存在することが判明した。

本プラグインは委員会の「人間行動逆工学」プロジェクトの段階的成果として、関連する必要を持つ利用者に対し、反復観測、記録、及び交差検証を経た行動実行の参照枠組みを提供するものである。収録された全てのプロトコルは、1,400 例を超える実在の人間個体に対する秘匿観察とデータ分析（信頼区間 ±12%）に基づいている。

委員会は厳かに声明する：本プラグインの提供する内容はあくまで参考であり、いかなる形式の行動処方を構成するものではない。利用者は実際の実行に先立ち、具体的な場面、文化的文脈、及び個体差に応じた適応的調整を行うこと。

## 中核的特性

- **収録範囲の補足**：中国語版は365項目（大分類12・小分類31）を収録し、日本語・ラテン語・古代ギリシャ語版は各10項目の基礎プロトコルを収録
- **十項目の基礎生活プロトコルを完全網羅**：生物維持類（摂食、休眠、気体交換、液体摂取、視覚センサー保守）と社交融入類（二足移動、非脅威信号発信、資源交換儀式、多ノード通信、前肢連結）の二大行動体系を包含
- **四段階の情報密度適応**：「簡明」「標準」「詳細」「学術」の四種の出力粒度を提供し、単一カード速覧から参考文献を含む完全学術檔案まで、様々な認知階層の参照需要に応える
- **多ソース交差検証出力**：プロトコル内容は生活標準委員会の下に設置された複数の仮想部門（安全審査班、延伸資料部、行動解読部、文献管理班等）により連名で発行され、実際の機関における多層審査過程をシミュレートする
- **安定した文書メタデータ**：同じ言語・行動項目では、再検索しても版番号、機密区分、編纂情報が変わらない
- **分類に関連する参考資料**：学術出力には行動テーマに関連する五件の資料を掲載し、同じ項目では引用内容も一定
- **ゼロ外部依存**：純粋な Python 標準ライブラリ + MaiBot SDK により実装され、サードパーティパッケージ依存ゼロ、展開コストは限りなくゼロに近い
- **四言語多言語対応**：プロトコル内容は中国語、ラテン語（Latīna）、古代ギリシャ語（Ἑλληνική）、日本語の四言語で個別に検索可能であり、各部局の署名及び延伸説明も対象言語に応じて切り替わる

## インストールと使用方法

### インストール

1. `life-behavior-reference` フォルダを MaiBot の `plugins/` ディレクトリに完全に複製する
2. `plugins/life-behavior-reference/_manifest.json`、`plugin.py`、`config.toml` の三ファイルがディレクトリ内に存在することを確認する
3. MaiBot を再起動するか、プラグイン管理パネルを通じてプラグインを読み込む

### 有効化

プラグインはインストール後、デフォルトで有効化される。手動制御が必要な場合：

1. `plugins/life-behavior-reference/config.toml` を開く
2. `[plugin]` セクションの `enabled` を `true` または `false` に設定する
3. MaiBot を再起動するか、設定のホットリロードを作動させる

### 使用方法

任意のチャットウィンドウで以下の形式のコマンドを送信する：

```
/rs <行動名>
```

例：

```
/rs しょくじ
/rs すいみん
/rs ほこう
/rs いんすい
```

`/rs もくじ` は現在の日本語版に収録された十項目を一覧表示する。中国語版から一件をランダムに選ぶには `/rs 生活参考`、中国語の分類を表示するには `/rs 生活参考 帮助` を使用する。分類は「大分類 > 小分類 > 具体的な項目」の順にたどれる。ラテン語版と古代ギリシャ語版の一覧コマンドは、それぞれ `/rs index` と `/rs πιναξ`。コマンド例は既定の `/rs` を使用しており、設定で変更できる。

## Fundāmentum Prōiectī

In commūtātiōnibus sociālibus cottīdiānīs, māior pars individuōrum hūmānōrum comportāmenta fundāmentālia — ingestiōnem, ambulātiōnem, rītūs sociālēs — nātūrāliter exsequentur, nūllā īnstrūctiōne externā necessāriā. Attāmen, Collēgium in observātiōnibus diūturnīs invēnit nōnnūllōs coetūs exhibēre dēfectum cognitīvum systēmaticum in exsecūtiōne normātā praedictōrum comportāmentōrum — manifestum per cōnfūsiōnem sequentiārum āctiōnum, errōrēs interpretātiōnis signōrum sociālium, et absentiam subroutīnārum crīticārum.

Hoc mūnus prōiectī "Ingeniāriae Inversae Comportāmentōrum Hūmānōrum" Collēgiī est refērentiam exsecūtiōnis comportāmentōrum praebēre, super observātiōnēs occultās et datos analyticōs plūs 1,400 individuōrum rēālium (intervāllum cōnfīdentiae ±12%) fundātam.

Collēgium sollemniter dēclārat: māteria hīc praebita sōlum referentiae causā datur, nec ūllō modō praescrīptiōnem comportāmentōrum cōnstituit. Ūsōrēs ante exsecūtiōnem rēālem sē accommodāre dēbent ad contextum specificum, cultūrālem, et differentiās indīviduālēs.
